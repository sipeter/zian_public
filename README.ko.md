# Zian - 로컬 우선 오프라인 음성 입력 도구

> 음성을 사용자의 기기에 그대로 보관합니다.
>
> 어떤 입력란에서든 말로 바로 입력하고, 스마트폰을 PC의 무선 마이크로 사용할 수도 있습니다.

## 제품 소개

Zian ([ziansoft.com](https://ziansoft.com))은 Windows용 로컬 음성 입력 및 전사 도구입니다.

음성 인식은 PC에서 실행되며 클라우드 음성 인식 서비스에 의존하지 않습니다. 문서 작성, 채팅, 코드 입력, 긴 오디오 및 동영상 파일 전사에 사용할 수 있습니다.

Android 및 iOS용 ZianLink를 사용하면 스마트폰을 로컬 네트워크로 PC에 연결하여 Zian의 무선 마이크로 사용할 수 있습니다.

## 주요 기능

- **로컬 음성 입력**: 기본적으로 `CapsLock`을 누른 채 말하고 키를 놓으면 현재 창에 텍스트가 입력됩니다. 단축키는 변경할 수 있습니다.
- **두 가지 로컬 인식 엔진**: 기본 SenseVoice와 필요할 때 설치할 수 있는 FunASR-Nano를 제공합니다. CPU 버전과 NVIDIA GPU 버전을 선택할 수 있습니다.
- **입력 교정 및 로컬 규칙**: 최근 입력을 빠르게 수정하고 반복되는 교정을 로컬 규칙으로 저장할 수 있습니다. 가장 최근 문장도 다시 불러올 수 있습니다.
- **Zian Scribe**: 오디오 및 동영상 파일 전사, 일괄 처리, 진행률 표시, 결과 미리보기 및 내보내기를 지원합니다.
- **ZianLink 스마트폰 마이크**: Android 휴대전화나 iPhone을 LAN을 통해 PC 마이크로 사용할 수 있습니다. Android는 길게 눌러 녹음과 탭 녹음을 지원합니다.
- **유연한 텍스트 입력 방식**: 편집기, 채팅 앱, 게임에 따라 클립보드 붙여넣기 또는 키보드 입력 시뮬레이션을 선택할 수 있습니다.
- **선택형 문장 정리**: 문장 부호 처리, 사용자 지정 규칙, AI 보조 다듬기를 필요할 때 사용할 수 있습니다.
- **사용자 요청 방식 업데이트 확인**: 사용자가 직접 실행할 때만 업데이트를 확인하며 백그라운드에서 자동으로 확인하지 않습니다.

## 개인정보 보호

Zian의 음성 인식 코어는 로컬에서 실행되며 클라우드 인식을 위해 녹음이나 전사 내용을 업로드하지 않습니다.

라이선스 활성화, 사용자가 시작한 업데이트 확인, 선택형 모델 다운로드는 인터넷에 접속할 수 있습니다. 스마트폰 마이크 음성은 로컬 네트워크로 전송되며 PC의 로컬 모델에서 처리됩니다.

## 지원 플랫폼

### Windows

- Windows 10 / 11 64비트
- CPU 및 NVIDIA GPU 버전
- 설치 프로그램 및 포터블 패키지
- 8 GB 이상의 메모리 권장
- .NET Framework 4.7.2 이상

### Android - ZianLink

- Android 휴대전화를 PC용 Zian의 무선 마이크로 사용
- 길게 눌러 녹음 및 탭 녹음
- Google Play 또는 APK로 배포

### iOS - ZianLink

- iPhone을 PC용 Zian의 무선 마이크로 사용
- 녹음 제어 및 입력 완료 피드백
- IPA를 설치하려면 서명이 필요합니다

## 빠른 시작

1. PC에 맞는 CPU 또는 GPU 버전을 다운로드합니다.
2. 설치 프로그램을 실행하거나 포터블 패키지를 특수 문자가 없는 경로에 압축 해제합니다.
3. `Zian.exe`를 실행하고 시스템 트레이 아이콘이 나타날 때까지 기다립니다.
4. 입력란을 선택하고 `CapsLock`을 누른 채 말한 다음 키를 놓아 텍스트를 입력합니다.
5. 스마트폰 마이크를 사용하려면 PC에서 ZianLink를 활성화하고 스마트폰으로 연결합니다.
