# zian - ローカル優先のオフライン音声入力ツール

PC **v0.9.7.0**：[ダウンロードと更新内容](https://github.com/sipeter/zian_public/releases/tag/v0.9.7.0)。スマートフォン用 Link は v0.9.5.0 のままです。

>
> あらゆる入力欄へ音声で直接入力でき、スマートフォンをPCのワイヤレスマイクとして使用することもできます。

## 製品紹介

zian ([ziansoft.com](https://ziansoft.com)) は、Windows向けのローカル音声入力・文字起こしツールです。

音声認識はPC上で実行され、クラウド音声認識サービスに依存しません。文書作成、チャット、コード入力、長時間の音声・動画ファイルの文字起こしに利用できます。

AndroidおよびiOS向けのZianLinkを使うと、スマートフォンをローカルネットワーク経由でPCに接続し、Zianのワイヤレスマイクとして利用できます。

## 主な機能

- **ローカル音声入力**：初期設定では `CapsLock` を押しながら話し、離すと現在の画面へ文字を入力します。ホットキーは変更できます。
- **4つのローカル認識モデル**：SenseVoice を標準搭載し、FunASR Nano、Qwen3-ASR 0.6B / 1.7B を追加できます。CPU 版と NVIDIA GPU 版を提供しています。
- **モデル管理**：設定からモデルのダウンロード、オフライン ZIP の読み込み、整合性確認、削除ができます。アプリ更新時も独立したモデルフォルダーは保持されます。
- **入力修正とローカルルール**：直前の入力をすばやく修正し、よく使う修正をローカルルールとして保存できます。直近の一文も呼び戻せます。
- **zian Scribe**：音声・動画ファイルの文字起こし、バッチ処理、進捗表示、プレビュー、書き出しに対応します。
- **ZianLinkスマートフォンマイク**：Android端末やiPhoneをLAN経由でPCのマイクとして利用できます。Androidは長押し録音とタップ録音に対応します。
- **柔軟な文字入力方式**：クリップボード貼り付けとキーボード入力のシミュレーションを、エディター、チャット、ゲームに応じて選べます。
- **任意の文章整理**：句読点処理、カスタムルール、AI支援による文章調整を必要に応じて利用できます。
- **ユーザー操作による更新確認**：更新確認はユーザーが実行したときだけ行い、バックグラウンドで自動確認しません。

## プライバシー

Zianの音声認識コアはローカルで動作し、クラウド認識のために録音や文字起こし内容をアップロードしません。

ライセンス認証、ユーザーが開始した更新確認、追加モデルのダウンロードではインターネットに接続する場合があります。スマートフォンの音声はローカルネットワークを通り、PC上のローカルモデルで処理されます。

## 対応プラットフォーム

### Windows

- Windows 10 / 11、64ビット
- CPU版とNVIDIA GPU版
- インストーラー版とポータブル版
- 8 GB以上のメモリを推奨
- .NET Framework 4.7.2以降

### Android - ZianLink

- Android端末をPC版Zianのワイヤレスマイクとして使用
- 長押し録音とタップ録音
- Google PlayまたはAPKで配布

### iOS - ZianLink

- iPhoneをPC版Zianのワイヤレスマイクとして使用
- 録音操作と入力完了フィードバック
- IPAのインストールには署名が必要です

## クイックスタート

1. PCに適したCPU版またはGPU版をダウンロードします。
2. インストーラーを実行するか、ポータブル版を特殊文字を含まないパスへ展開します。
3. `Zian.exe` を起動し、タスクトレイにアイコンが表示されるまで待ちます。
4. 入力欄を選択し、`CapsLock` を押しながら話して、離すと文字が入力されます。
5. スマートフォンをマイクとして使う場合は、PCでZianLinkを有効にしてスマートフォンから接続します。
